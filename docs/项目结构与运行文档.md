# shuitool3 运行文档

> 基于《shuitool项目分析与前端重构建议.md》重写的直播弹幕互动工具箱。
> 技术栈：Flask 3（后端）+ Vue 3 / Vite / TypeScript / Pinia / Element Plus（前端）。

## 二、后端路由一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/stream` 或 `/events` | SSE 事件流（前端统一监听） |
| POST | `/connect_services` | 连接 B站弹幕（json `code/livecode` 或 form `livecode/code`） |
| GET | `/disconnect_services` | 断开弹幕连接 |
| GET | `/connection_status` | 连接状态 |
| GET | `/loadSettings` | 读取全部设置 |
| POST | `/changeValue` | 修改设置（支持嵌套 key 与扁平 form） |
| GET | `/setting/fontdict` | 字体字典 |
| GET | `/open-queue` / `/close-queue` | 开启 / 关闭排队 |
| GET | `/clear-queue` | 清空队列 |
| GET | `/get_queue` | 返回 `{queue, music, all_queue}` |
| POST | `/update_queue_list` | 更新队列列表（json `queue_list` 或 form `list` 逗号串） |
| GET | `/open-music` / `/close-music` | 开启 / 关闭点歌 |
| GET | `/nextMusic` | 切歌 |
| GET | `/catch_playing` | 同步当前播放状态 |
| POST | `/update_music_list` | 更新点歌列表（json `music_list` 或 form `list`） |
| GET | `/findPath` | 探测游戏目录 |
| GET | `/change2mhy` / `/change2b` | 切换原神 / 崩铁服务器（路径白名单保护） |
| GET | `/startGame` | 启动游戏 |
| GET | `/prepare` | 换服预处理 |
| GET | `/get_cookies` / POST `/savecookies` | 读取 / 保存刷屏 cookies |
| GET | `/start_sender` / `/stop_sender` / `/sender_status` | 自动刷屏控制 |
| GET/POST | `/ai/config` | 读写 AI 聊天配置（POST 合并写入，key 脱敏） |
| GET | `/ai/status` | AI 服务商连通状态（60s 缓存） |
| POST | `/ai/test` | 连通性测试 / 测试回复（`mode: ping\|chat`） |
| POST | `/ai/send` | 手动触发一条 AI 回复（测试区，走完整链路） |
| POST | `/ai/stream` | 流式测试回复（SSE 打字机：delta → done/error） |
| GET | `/ai/logs` | 交互日志（内存 60 条 + 落盘 temp/ai_chat.log） |
| GET | `/ai/models` | 拉取运行时已安装模型列表（Ollama /api/tags；llama.cpp/LM Studio /models） |
| GET | `/` | 前端管理页（static 托管） |
| GET | `/assets/<path>` | 前端静态资源 |
| GET | `/<path>` | 前端 SPA 回退（history fallback 由 hash 路由兜底） |

## 三、SSE 事件表

| 事件 | 载荷 | 触发时机 |
|---|---|---|
| `queue_changed` | `{queue, music}` | 排队开关 / 清空 / 列表更新 |
| `music_changed` | `{music, queue}` 或列表 | 点歌开关 / 切歌 / 列表更新 |
| `queue_status_changed` | `{queueEnabled}` | 排队开关状态变化 |
| `music_status_changed` | `{musicEnabled}` | 点歌开关状态变化 |
| `settings_changed` | 设置片段 | `changeValue` 保存成功 |
| `connection_changed` | `{biliclientRunning}` | 弹幕连接 / 断开 |
| `danmu` | `{uid, uname, msg, ...}` | 收到弹幕（console 实时流） |
| `sender_changed` | `{running}` | 刷屏启动 / 停止 |

## 四、启动与运行

### 0. 环境要求

- Python 3.10+（开发环境已验证 3.11）
- Node.js 18+（开发环境已验证 v22）

### 1. 安装依赖

```powershell
# 后端
pip install -r E:\Users\shuis\python\shuitool3\backend\requirements.txt

# 前端（如需开发 / 重新构建）
cd E:\Users\shuis\python\shuitool3\frontend
npm install
```

> 注意：`blivedm` 与 `websockets` 若 requirements 中未覆盖，需单独安装：
> `pip install blivedm websockets`

### 2. 方式 A：生产模式（推荐日常使用，单端口）

```powershell
cd E:\Users\shuis\python\shuitool3\backend
python main.py
```

浏览器打开 `http://127.0.0.1:5000`。前端静态文件由 Flask 托管，无需另起服务。

> 若修改了前端源码，需先构建再启动（见下）：
> ```powershell
> cd E:\Users\shuis\python\shuitool3\frontend
> npm run build   # 输出到 backend/static
> ```

### 3. 方式 B：开发模式（前后端分离，热更新）

终端 1（后端）：
```powershell
cd E:\Users\shuis\python\shuitool3\backend
python main.py
```

终端 2（前端 Vite dev server）：
```powershell
cd E:\Users\shuis\python\shuitool3\frontend
npm run dev     # http://localhost:5173，/api、/events 等已代理到 5000
```

### 4. 配置准备

启动前检查 `E:\Users\shuis\python\shuitool3\settings\settings.json`：

- **B站开放平台**：填写 `openlive` 段的 `app_id / app_secret / access_key`（弹幕连接 `connect_services` 使用）
- **洛雪音乐**：点歌依赖本机已安装并登录的洛雪音乐（LX Music），通过 `lxmusic://` scheme 调起；歌词页直连其本地 SSE `http://localhost:23330/subscribe-player-status`
- **一键换服**：`game` 相关路径需指向真实游戏安装目录（`findPath` 可探测）

### 5. 功能清单

| 功能 | 入口 | 依赖 |
|---|---|---|
| B站弹幕接收 / 实时弹幕流 | 排队页 / 控制台页 | B站开放平台凭据 |
| 弹幕排队 / 点歌 / 切歌 / 礼物 | 排队页 + 点歌页 | blivedm + 洛雪音乐 |
| 歌词同步（SSE 直连 LX） | 歌词页 + `/display/lyrics` | LX Music 本地服务 |
| 自动刷屏 | 刷屏页（cookies + 内容） | cookies.json |
| AI 弹幕聊天 | AI 页（总开关 + 触发/限流/上下文/过滤） | 本地模型（Ollama / llama.cpp / LM Studio）或云端 OpenAI 兼容 API |
| 一键换服 | 换服页 | 游戏目录 |
| OBS 叠加展示 | `/display/queue`、`/display/music`、`/display/lyrics` | OBS 浏览器源 |

### 6. 常见问题

- **500 错误**：先看后端控制台 traceback；确认 `settings/*.json` 为合法 JSON。
- **弹幕连不上**：确认开放平台凭据已填且未过期；`connection_status` 查看状态。
- **点歌无效**：确认洛雪音乐已启动并登录；`lxmusic://` scheme 需系统已注册（安装 LX Music 后自动注册）。
- **换服无效**：确认 `findPath` 找到的游戏目录有效，路径含空格时后端已做引号与白名单保护。
